# Обновления «Переплёта»

`Pereplet.apk` — установочная сборка Android 1.23. Её можно установить поверх прежней версии с сохранением данных.

Канал обновлений — **1.23**. Добавлены начальная порция ленты из 10 книг, цветовые темы, многовыбор стран, статусы чтения, переходы по автору, жанру и стране, отметки глав и управление размером текста жестом. «Чёрный человек» Есенина включён в приложение по открытому тексту iLibrary.ru.

Приложение проверяет `pereplet-channel.json` при открытии и каждые две минуты, пока оно открыто. В меню «Выбрать версию» доступны предыдущие выпуски из `versions/`; версия 1.15 встроена в APK.

Пакеты обновлений подписаны. Ключ подписи хранится локально и в репозиторий не загружается.
