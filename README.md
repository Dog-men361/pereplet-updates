# Обновления «Переплёта»

`Pereplet.apk` — установочная версия Android 1.25.1. Её можно установить поверх прежней версии с сохранением локальной библиотеки и настроек.

В версии 1.25.1 исправлена цветная рамка статуса: по всему периметру карточки теперь одна линия одинаковой толщины.

В 1.25 статусы книг по умолчанию окрашены так: «Планирую» — жёлтый, «Читаю» — оранжевый, «Прочитал» — зелёный, «Брошено» — красный. Цвет каждого статуса можно менять в настройках. Сердце в карточке книги находится слева от крестика закрытия.

В 1.24 добавлены фоновый поиск открытого русского текста при открытии карточки и отдельная лента авторов. DjVu.online есть в справочнике каталогов; автоматический импорт оттуда не включён, права проверяются для каждого документа отдельно.

Приложение проверяет канал при открытии и далее каждые две минуты, пока оно работает. Предыдущие версии доступны в меню «Выбрать версию». Пакеты обновлений подписаны; ключ подписи хранится локально и в репозиторий не загружается.
