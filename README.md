# Обновления «Переплёта»

`Pereplet.apk` — установочная версия Android 1.28.3. Установи её поверх прежней, чтобы включить проценты загрузки обновления и разрешённый запрос данных о годах жизни автора; библиотека и настройки сохранятся. Android-часть приложения обновляется APK, а каталог и интерфейс — подписанным пакетом в приложении. Текущая версия каталога — 1.29.

В 1.28 добавлен выбор языка полного текста. Поиск запускается только после выбора языка и ищет открытые полные тексты Project Gutenberg; в 1.28.1 он проверяет несколько вариантов названия книги, включая испанское, и совпадение по названию. Книги не загружаются заранее и не добавляются в APK. Если открытого полного текста нет, читалка сообщит об этом.

Дата и время выпуска показываются в истории доступных версий и уведомлении. Тестовая сборка 1.17 больше не предлагается для отката. Автообновление проверяет канал при запуске и далее каждые две минуты, пока приложение работает. Пакеты обновлений подписаны; ключ подписи хранится локально и в репозиторий не загружается.

В 1.28.2 рамка статуса книги появляется сразу после выбора. В 1.28.3 исправлена привязка статуса к встроенным книгам: цвет появляется сразу, а повторный выбор не сбрасывает его. Загрузка обновления показывает фактический процент, карточка автора автоматически ищет годы жизни и открытые произведения; список подгружается по мере прокрутки. В 1.29 восстановлена история выпусков: версии сравниваются по числовым компонентам, поэтому записи 1.28.1–1.28.3 отображаются корректно. Новые каталожные обновления используют единый формат 1.29, 1.30 и далее.

Автоматический поиск идёт через шесть подключённых каталогов: Викитеку, Project Gutenberg, Internet Archive, Google Books, Library of Congress и Open Library. В настройках также перечислены дополнительные библиотеки, но это справочник: многие не предоставляют открытый API, требуют ключ, читательский билет или отдельное подтверждение прав. Они не обозначены как автоматически подключённые источники. Такой режим избегает сотен одновременных запросов и не выдаёт записи каталога за гарантированно читаемый текст.
