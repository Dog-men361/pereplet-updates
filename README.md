# Обновления «Переплёта»

`Pereplet.apk` — установочная версия 1.15. Ставится поверх предыдущей версии приложения.

Приложение проверяет `pereplet-channel.json` при открытии и каждые две минуты, пока оно открыто. Если версия новее установленной, оно показывает окно с кнопкой «Обновить». После нажатия загружает подписанный `pereplet-update.pereplet` и запускает его. В меню «Выбрать версию» можно вернуться к встроенной версии 1.15; архивы следующих выпусков хранятся в `versions/`.

Для публикации следующей версии нужно собрать HTML и книжные ресурсы, создать подписанный пакет через `work/pereplet-android/pack-update.ps1`, проверить его и обновить три файла канала: JSON-манифест, текущий пакет и архив `versions/<код>.pereplet`. Ключ подписи хранится локально и в репозиторий не загружается.
