# Обновления «Переплёта»

`Pereplet.apk` — установочная версия Android 1.27. Её можно установить поверх прежней версии с сохранением локальной библиотеки и настроек.

В 1.27 загрузка текста книги занимает весь экран читалки. Лента авторов показывает следующие порции по мере прокрутки и может находить новые имена по проверенным открытым произведениям Викитеки. В каталоге есть описания и варианты названий для семи основных романов «Гарри Поттера» и пяти вышедших романов «Голодных игр».

Карточки современных серий содержат только библиографические сведения и краткие описания. Полные тексты защищённых авторским правом книг не встроены; приложение открывает текст только из доступного открытого источника.

Приложение проверяет канал при открытии и далее каждые две минуты, пока оно работает. Предыдущие версии доступны в меню «Выбрать версию». Пакеты обновлений подписаны; ключ подписи хранится локально и в репозиторий не загружается.
