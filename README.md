# Обновления «Переплёта»

`Pereplet.apk` — установочная версия Android 1.25. Её можно установить поверх прежней версии с сохранением локальной библиотеки и настроек.

В 1.25 статусы книг получили цвета по умолчанию: «Планирую» — жёлтый, «Читаю» — оранжевый, «Прочитал» — зелёный, «Брошено» — красный. Цвет каждого статуса меняется в настройках; есть возврат к исходным цветам. Сердце в карточке книги расположено слева от крестика закрытия.

В 1.24 добавлены фоновый поиск открытого русского текста при открытии карточки, отдельная лента авторов и цветные рамки статусов. Исправлены перекрытия меню; окна обновлений и выбор размера порции оформлены в стиле приложения.

DjVu.online есть в справочнике каталогов. Автоматическая загрузка его книг не включена: права зависят от конкретного документа. Внутренняя читалка ищет полный текст в открытых источниках с проверяемыми условиями доступа.

Приложение проверяет канал при открытии и далее каждые две минуты, пока оно работает. Предыдущие версии доступны в меню «Выбрать версию». Пакеты обновлений подписаны; ключ подписи хранится локально и в репозиторий не загружается.
