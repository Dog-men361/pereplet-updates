# Обновления «Переплёта»

`Pereplet.apk` — установочная версия Android 1.26. Её можно установить поверх прежней версии с сохранением локальной библиотеки и настроек.

В 1.26 окно автообновления оформлено в тёмном стиле приложения, а меню сортировки расположено над обложками. Для старой APK-сборки, которая показывает системное серое окно обновления, потребуется один раз установить новый APK: веб-пакет OTA не меняет Android-часть приложения.

В версии 1.25 добавлены настраиваемые цвета статусов книг и сердце слева от крестика карточки. Рамка статуса сделана одинаковой толщины.

Приложение проверяет канал при открытии и далее каждые две минуты, пока оно работает. Предыдущие версии доступны в меню «Выбрать версию». Пакеты обновлений подписаны; ключ подписи хранится локально и в репозиторий не загружается.
