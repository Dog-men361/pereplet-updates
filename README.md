# Обновления «Переплёта»

`Pereplet.apk` — установочная сборка Android 1.22. Её можно установить поверх прежней версии с сохранением данных. Для доступа к Library of Congress требуется APK 1.22: в нём обновлён сетевой список Android-разрешений.

Канал обновлений — **1.22**. Добавлен поиск полного русского OCR-текста в открытом фонде Library of Congress. Карточки-каталоги при чтении повторно проверяются по подключённым открытым полнотекстовым источникам.

Приложение проверяет `pereplet-channel.json` при открытии и каждые две минуты, пока оно открыто. В меню «Выбрать версию» доступны предыдущие выпуски из `versions/`; версия 1.15 встроена в APK.

Пакеты обновлений подписаны. Ключ подписи хранится локально и в репозиторий не загружается.
