# Обновления «Переплёта»

`Pereplet.apk` — установочная версия Android 1.24. Её можно установить поверх прежней версии с сохранением локальной библиотеки и настроек.

Канал обновлений — **1.24**. Новая версия заранее ищет доступное русское издание при открытии карточки, добавляет отдельную ленту авторов, окрашивает рамки книг по статусу чтения и исправляет слои меню. Центр обновлений и выбор размера порции оформлены в стиле приложения.

DjVu.online добавлен в справочник каталогов. Автоматическая загрузка его книг не включена: права зависят от конкретного документа. Внутренняя читалка ищет полный текст в открытых источниках с проверяемыми условиями доступа.

Приложение проверяет канал при открытии и далее каждые две минуты, пока оно работает. Предыдущие выпуски доступны в меню «Выбрать версию». Пакеты обновлений подписаны; ключ подписи хранится локально и в репозиторий не загружается.
