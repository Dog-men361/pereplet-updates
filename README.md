# Обновления «Переплёта»

`Pereplet.apk` — базовая установочная сборка 1.15. После установки приложение проверяет канал обновлений и предлагает установить последнюю подписанную версию.

Текущая версия канала — **1.21**. В неё добавлен справочник 42 книжных ресурсов с пояснениями об открытом доступе, регистрации и библиотечных ограничениях. Автоматический поиск и встроенная читалка используют подключённые открытые источники. Доступ к закрытым и платным текстам не обходится.

Приложение проверяет `pereplet-channel.json` при открытии и каждые две минуты, пока оно открыто. В меню «Выбрать версию» доступны текущая и прежние выпуски из `versions/`; версия 1.15 встроена в APK.

Пакеты обновлений подписаны. Ключ подписи хранится локально и в репозиторий не загружается.
