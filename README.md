# Обновления «Переплёта»

`Pereplet.apk` — установочная версия Android 1.28. Её можно установить поверх прежней версии с сохранением локальной библиотеки и настроек.

В 1.28 в читалке можно выбрать язык оригинала. Поиск запускается только по выбору языка и использует доступные общественные тексты Project Gutenberg; тексты книг не скачиваются заранее и не добавляются в приложение. Если полного открытого текста нет, читалка сообщит об этом. Добавлены дата и время выпуска в уведомление и список доступных версий. Удалены тестовая метка и лишние пояснения из настроек.

Обновление проверяется при запуске и далее каждые две минуты, пока приложение работает. Предыдущие версии доступны в меню «Выбрать версию». Тестовая сборка 1.17 больше не предлагается для отката. Пакеты обновлений подписаны; ключ подписи хранится локально и в репозиторий не загружается.
